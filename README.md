# keros68

科研工作用的 Agent Skill，以及 AI 编程 Agent 的本地辅助工具。

## 科研 Skill

统一收录在 [xiaoyu-skill](https://github.com/keros68/xiaoyu-skill)，每个 Skill 可单独安装，支持 Claude Code、Codex 等可加载 `SKILL.md` 的 Agent。

| Skill | 用途 |
|-------|------|
| [academic-reference-matcher](https://github.com/keros68/xiaoyu-skill/tree/main/skills/academic-reference-matcher) | 为论文中的论述补充、核验和格式化参考文献，支持 GB/T 7714、APA、BibTeX |
| [sci-select](https://github.com/keros68/xiaoyu-skill/tree/main/skills/sci-select) | SCI 期刊候选筛选、影响因子与分区查询、按目标期刊要求做投稿前检查 |
| [abstract-fig](https://github.com/keros68/xiaoyu-skill/tree/main/skills/abstract-fig) | 绘制可编辑的图形摘要、机制图和技术路线图（draw.io） |
| [study-area-map](https://github.com/keros68/xiaoyu-skill/tree/main/skills/study-area-map) | 绘制研究区区位图、地形底图和采样点专题图（R） |
| [cugb-doctoral-thesis-format](https://github.com/keros68/xiaoyu-skill/tree/main/skills/cugb-doctoral-thesis-format) | 中国地质大学（北京）博士学位论文 Word 格式检查 |
| [ai-cross](https://github.com/keros68/xiaoyu-skill/tree/main/skills/ai-cross) | 把任务分派给多个模型执行，并由不同厂商的模型交叉核查结果 |

## AI Agent 工具

| 项目 | 用途 |
|------|------|
| [metrik](https://github.com/keros68/metrik) | 集中查看本机各 AI 服务的配额余量和 Token 用量，支持 ChatGPT、Claude、GLM、Kimi 等 |
| [yourmem](https://github.com/keros68/yourmem) | 归档和搜索 Claude Code、Codex、Kimi 等 Agent 的本地会话，保存项目记忆 |
| [ProjectBridge](https://github.com/keros68/ProjectBridge) | 连接 ChatGPT 网页端与本机 Codex，在授权的本地项目上协作 |
| [niulai](https://github.com/keros68/niulai) | Agent 任务完成提醒桌宠，支持 Claude Code、Codex、Gemini、Kimi Code |
